CSS 삽입 관련 자주 묻는 질문

Q CSS 파일이 너무 길어서 전부 복사가 안 돼요

위의 큰 복사 버튼을 사용하거나, Ctrl+A로 전체 선택 후 Ctrl+C를 사용하면 아무리 긴 파일이어도 한 번에 복사됩니다. 마우스 드래그로 선택하면 일부만 선택될 수 있으니 반드시 Ctrl+A를 먼저 사용하세요.

Q 아임웹에서 코드 삽입 메뉴를 찾을 수 없어요

아임웹 버전에 따라 위치가 다릅니다. 아래 순서로 시도해보세요:

  1. 편집기 좌측 패널 맨 아래 ⚙ 설정 아이콘 클릭
  2. 편집기 상단 메뉴 사이트 설정 텍스트 클릭
  3. 아임웹 관리자(imweb.me) → 해당 사이트 관리 → 환경설정 → 코드 직접 입력 탭

어느 경로든 "HEAD 영역" 또는 "<head> 코드 삽입"이라고 된 입력창을 찾으면 됩니다.

Q 저장했는데 미리보기에서 디자인이 안 보여요

아래 순서로 확인하세요:

  1. 코드 삽입 창을 다시 열어서 내용이 남아 있는지 확인 (없으면 다시 붙여넣기 후 저장)
  2. <style> 태그와 </style> 태그가 모두 있는지 확인
  3. CSS 내용이 두 태그 사이에 있는지 확인
  4. HTML 섹션을 아직 추가하지 않았다면 빈 화면이 정상 — HTML 섹션 추가 후 다시 확인
  5. 브라우저 캐시 삭제 후 미리보기 새로고침 (Ctrl+Shift+R)
Q 폰트가 기본 폰트로 보여요 (Noto Serif KR 미적용)

Google Fonts 링크(PART A)가 <style> 태그 위에 있는지 확인하세요.

구조: <link href="fonts.googleapis.com/..."> → (이 다음 줄에) → <style>CSS내용</style>

또한 인터넷 연결 상태가 양호해야 하며, 광고 차단기나 방화벽이 Google Fonts를 차단할 수 있습니다.

Q 모바일에서 디자인이 PC와 달라요

css/style.css에는 반응형(미디어쿼리) 스타일이 이미 포함되어 있습니다. 모바일 화면이 이상하게 보인다면:

  • CSS를 완전히 복사했는지 확인 (파일 맨 아래까지 복사되어야 함)
  • 아임웹 에디터에서 모바일 미리보기 탭으로 확인
  • 아임웹 자체 모바일 설정이 CSS를 덮어쓰는 경우가 있을 수 있음
Q JS(JavaScript)도 같은 방법으로 넣나요?

JS는 BODY 하단 탭에 넣어야 합니다. js/main.js 파일 전체 내용을 <script>와 </script> 태그로 감싸서 BODY 하단 탭에 붙여넣기합니다.

<script>
  /* js/main.js 내용 전체 붙여넣기 */
</script>

자세한 내용은 전체 아임웹 적용 가이드를 참고하세요.
